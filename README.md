# Сервис сравнения цен между маркетплейсами Ozon и Wildberries

Это веб-приложение, которое позволяет пользователю быстро сравнивать цены на одинаковые товары в двух популярных маркетплейсах - Ozon и Wildberries.

## — — — Суть проекта — — —

Сегодня большинство людей совершают покупки онлайн. Однако цены на один и тот же товар на разных платформах часто значительно отличаются.
Чтобы найти выгодное предложение, покупателю приходится вручную искать товар на каждом сайте, сравнивать цену, характеристики и т.д.. Это неудобно и отнимает много времени.

Цель проекта — упростить этот процесс: создать сервис, который автоматически находит и сравнивает товары на двух площадках и показывает, где выгоднее купить.


## — — — Как работает система и какие технологии будут использоваться — — —

Пользователь вводит название интересующего товара. Приложение отправляет запрос на сервер, где происходит автоматический сбор данных с сайтов Ozon и Wildberries.
Программа извлекает название товара, цену, ссылку и возможно что-то еще придумаем во время разработки. После этого результаты объединяются и выводятся в виде одной "карточки", в которой указаны цены на обоих маркетплейсах и ссылки на оригинальные страницы товара.

С технической стороны проект реализован на следующих технологиях (в приоритетном порядке этапов разработки)

Backend: Python с использованием фреймворка FastAPI — отвечает за обработку запросов и взаимодействие с парсерами.
Парсинг данных: библиотеки Requests, BeautifulSoup(эт для вб - просто достает данные из html) и Playwright(эт для озона, эмулятор браузера), которые позволяют получать и анализировать HTML-страницы и API-запросы маркетплейсов.

База данных: SQLite — используется для хранения истории запросов и кэширования результатов, чтобы ускорить работу приложения. (возможно ЛК для пользователей)

Frontend: HTML + JS — интерфейс, через который пользователь взаимодействует с системой.

Дизайн и UX — придумать минималистичный, удобный внешний вид и обязательно сделать адаптивность под телефон.

и это все конечно сопровождается промежуточным и конечным тестированием

## — — — Практическая значимость — — —

Сервис экономит пользователям время и помогает находить лучшие цены.
Для продавцов он может быть полезен как инструмент анализа рыночных цен и конкурентов.
В дальнейшем проект можно развивать: добавить Яндекс.Маркет, Aliexpress и др., реализовать уведомления о снижении цен, историю изменения стоимости и много другое. 


## — — — Что по монетизации? — — —

Монетизация проекта может строиться на партнёрских программах Ozon, Wildberries, ЯМ и др: при переходе по специальной ссылке и оформлении покупки мы получаем небольшой процент от суммы заказа. Также реклама: размещение рекламируемых товаров и другое. В будущем можно реализовать платные функции, например уведомления о снижении цен, уведомления об акциях, удаление рекламы или историю изменения стоимости.
