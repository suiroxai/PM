# Сервис сравнения цен между маркетплейсами Ozon и Wildberries

Это веб-приложение,  которое позволяет пользователю быстро сравнивать цены на одинаковые товары в двух популярных маркетплейсах  -  Ozon и Wildberries.

Данная версия проекта не окончательна, поэтому в финальной версии могут быть кординальные отличия. Работы ведутся. При возникновении ошибок добро пожаловать в раздел Issues на Githab. 
# **Как запустить**
Для ознакомления проекта предлагается 3 способа от самого простого к сложному и менее рекомендуемому

## Способ 1. Сайт.
Можете перейти по ссылке и ознакомится с тестовой версией сайта http://193.247.73.234:8000/. На сервере версия может быть не актуальной. 
## Способ 2. Docker.
Вы скачиваете проекта себе на компьютер и разворачивате его в докер контейнере. 
 1. Скачайте проект командой
```
git clone https://github.com/suiroxai/PM.git
```
2. Зайдите в папку проекта
```
cd PM
```
3.  Соберите контейнер, может потребоваться около 10 минут
```
docker build -t pricecomp .
```
4.  Запустить контейнер можно командой 
```
docker run -d -p 8000:8000 pricecomp
```
Теперь когда у  вас работает контейнер можете перейти на http://localhost:8000/ и насладиться проектом.
## Способ 3. Установка и запуск на свой компьютер.
В проекте используются приложения чувствительные к операционной системе (так что у вас проект может просто не запуститься). Настоятельно рекомендуется воспользоваться контейнерами. Все делать на свой страх и риск. Для запуска на кмпьютере должен стоять Python>=3.8.
 1. Скачайте проект командой
```
git clone https://github.com/suiroxai/PM.git
```
2. Зайдите в папку проекта
```
cd PM
``` 
3. Создайте виртуальное окружение питона
```
`python -m venv venv`
```
4. Активируйте его
```
#Windows
venv\Scripts\activate

#macOS/Linux
source venv/bin/activate
```
5. Установка библиотек и зависимостей 
```
pip install --no-cache-dir -r requirements.txt  
camoufox fetch  
playwright install-deps
```
6. Запуск проекта. (Из папки app!!)
```
#Переходим в папку app
cd app

#Команда запуска 
uvicorn main:app --host 0.0.0.0 --port 8000
```
